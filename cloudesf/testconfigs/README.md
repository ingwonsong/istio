# ASM GOP Test Configs

This folders contains the test configs(*.json files) synced to ASM gob repo for
Cloud ESF/ASM e2e testing. They are generated by the
`apiserving/cloudesf/tests/endpoints/grpc_echo:grpc_echo_asm_e2e_config_asm_config_files`,
`apiserving/cloudesf/tests/e2e/endpoints/apikey_grpc:apikey_grpc_asm_e2e_config_asm_config_files`,
`apiserving/cloudesf/tests/e2e/endpoints/apikey_grpc:apikey_grpc_asm_e2e_http_backend_config_asm_config_files`
from the
[blueprint](http://google3/apiserving/cloudesf/cloudesf.blueprint;l=176-202;rcl=640980245)
and checked in by
[weekly rapid release automation](https://source.corp.google.com/piper///depot/google3/apiserving/cloudesf/release/brand_asm_release.pp)

For the details of our e2e test framework, please go to this
[doc](https://g3doc.corp.google.com/apiserving/cloudesf/team/g3doc/testing/asm_e2e.md).
